# 🚗 CodeAlpha Car Price Prediction

## 📌 Project Overview

This project is part of the CodeAlpha Machine Learning Internship.

The objective is to build a Machine Learning regression model that predicts the price of used cars based on different features such as:

- Brand
- Model
- Mileage
- Horsepower
- Fuel Type
- Transmission
- Engine Size
- Year
- Other vehicle specifications

The project follows the complete Machine Learning workflow from data preprocessing to model evaluation.
